## 2 最初のプログラム：Hello World

まずはプログラミングの伝統、画面に文字を表示させることから始めましょう。

```python
print("Hello, Python World!")
```

**解説:**

  * `print()` は、カッコの中身を画面に出力する**関数**です。
  * 文字を表示する場合は、シングルクォート `'` またはダブルクォート `"` で囲みます。

## 3 Pythonの基本構文

ここからは、プログラミングの基礎となる3つの要素「変数」「条件分岐」「繰り返し」を見ていきます。

### 3.1 変数とデータ型

変数は、データを入れておく「箱」のようなものです。

```python
# 数値の代入
age = 25
height = 170.5

# 文字列の代入
name = "Gemini"

# 出力
print(f"名前は{name}、年齢は{age}歳です。")
```

| データ型 | 説明 | 例 |
| :--- | :--- | :--- |
| `int` | 整数 | `10`, `-5` |
| `float` | 小数 | `3.14`, `0.5` |
| `str` | 文字列 | `"Hello"`, `'Python'` |
| `bool` | 真偽値 | `True`, `False` |

### 3.2 条件分岐 (if文)

「もし〇〇なら××する」という処理です。
Pythonの大きな特徴として、\*\*インデント（字下げ）\*\*を使ってブロックを表現します。

```python
score = 85

if score >= 90:
    print("評価：S")
elif score >= 70:
    print("評価：A")  # ここが実行されます
else:
    print("評価：B")
```

> **注意点:** インデント（通常はスペース4つ）がズレているとエラーになります。コードの見た目を揃えることが、Pythonではルールとして強制されます。

### 3.3 繰り返し (Loop)

決まった回数や、条件を満たす間、処理を繰り返します。

#### for文（回数が決まっている場合）

```python
# 0から4まで5回繰り返す
for i in range(5):
    print(f"{i}回目のループ")
```

#### while文（条件が満たされる間繰り返す）

```python
count = 0
while count < 3:
    print("まだ3未満です")
    count += 1
```

## 4 関数で処理をまとめる

同じ処理を何度も書くのは非効率です。「関数」を使って処理をパッケージ化しましょう。

```python
def calculate_bmi(weight_kg, height_m):
    """
    体重(kg)と身長(m)からBMIを計算する関数
    """
    bmi = weight_kg / (height_m ** 2)
    return bmi

# 関数の使用
my_bmi = calculate_bmi(60, 1.7)
print(f"あなたのBMIは {my_bmi:.2f} です")
```

**ポイント:**

  * `def` キーワードで関数を定義します。
  * `return` で計算結果を呼び出し元に返します。
